# Smriti

Independent Next.js foundation. Read prompt.md and DESIGN.md before continuing.

## Run

    cd apps/web
    npm ci
    npm run dev

## Checks

    npm run lint
    npx tsc --noEmit
    npm run build

Three routed pillars and explicitly labeled role previews are implemented. No authentication, database, voice API or clinical instrument is connected. No personal data is collected. Canonical assets and fonts are pending; neutral scaffolding is intentional. No Cybrion configuration is used.
