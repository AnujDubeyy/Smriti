# Smriti realtime gateway (experimental)
The gateway is a separately deployed, secure Prisma v3 WebSocket speech-to-text proxy. Browser audio uses PCM16LE, 16kHz mono, 512-sample (1024 byte) frames. Secrets stay on the gateway server. Signed short-lived tickets are minted via the Smriti Next.js app at /api/v1/voice/realtime-ticket only after an active, consent-gated voice session is checked.
This branch **does not** ship the complete UI, care-onboarding or database rollout. The full candidate source is available separately as Smriti_Care_Journey_Streaming_Gateway.zip; do not deploy this branch as a complete application or merge without integration, consent, security and clinical review.
Free tier: use Render web service from render.yaml, set GNANI_API_KEY_ID, SMRITI_GATEWAY_SECRET (random 32+ chars), SMRITI_ALLOWED_ORIGIN (exact HTTPS Smriti site). In the Next app set the same secret and NEXT_PUBLIC_SMRITI_GATEWAY_URL=wss://your-service.onrender.com/ws. Provider usage and cold starts may incur costs. Gnani documentation: https://docs.gnani.ai/api/STT/stt-websocket
This transports speech-to-text streaming only. Gemini conversation and Timbre audio are still request/response, not fully simultaneous full-duplex voice. Not tested against live Gnani credentials.
