# Asset provenance

Original supplied design-package files are retained unchanged in assets/svg and assets/mascots. Display assets use the supplied grandma wordmark and the three role-specific mascot references: red-bindi Assessment, yellow-flower Companionship, blue-collar Monitoring.

The display WebP copies remove surrounding whitespace and reduce file size without generating replacement artwork. The Assessment and Monitoring raster references are used because rendering the corresponding source SVGs produced clipped faces. PWA icons derive from the supplied grandma symbol. Originals remain available for design review.

Fonts: Nunito variable Latin, Baloo 2 Devanagari headings and Noto Sans Devanagari body, obtained from their Fontsource packages. Their included SIL Open Font License files are checked into public/fonts. Supplied Smriti branding is used as provided; no new redistribution license or ownership claim is invented.
